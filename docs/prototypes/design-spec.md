## 一、核心原则（用户已逐项确认）

1. **保持桌面端现有 UI 界面完全不变**：启动仍直达做题页（`dist/index.html`），不修改原有布局结构、不新增“准备就绪”等多余文字，只在现有界面上叠加新增入口和弹窗。
2. **顶栏右侧保持纯图标（Logo）风格**：
   - **删除原「我的进度 / 进度统计」图标（`#nav-progress`）**，用 **学习计划图标（`📅`）** 替代（右上角微角标显示今日待复习数量）。
   - **保留原所有其他按钮**：工作区布局按钮（`⊞`）、计时器（`⏱`）、深浅主题切换（`☀/☾`）、退出本地服务（`⏹`）。
   - **新增顶栏纯图标按钮**（悬停显示中文提示，不放文字撑宽）：
     - `📅` **学习计划**（打开居中浮层弹窗）
     - `☁` **腾讯云同步**（右下微圆点：绿=已同步 / 蓝脉冲=同步中 / 灰=离线 / 黄=存在冲突）
     - `⬇` **导出 / 导入备份**（保留现有本地备份/恢复能力）
     - `↺` **重置数据**（打开分层重置弹窗：仅重置学习计划 / 重置所有数据）
     - `👤` **力扣登录**（与 VS Code 插件一致，登录后右下亮力扣橙点）
3. **双主题完全对齐现有桌面端 Token**：严格复用 `dist/leetcode.css`、`dist/workspace.css`、`dist/local.css`、`dist/polish.css` 的深色 / 浅色色板、难度色与考察频次标签。

## 二、学习计划弹窗规格

- **形态**：居中浮层弹窗（覆盖在暗化/微模糊的现有做题界面之上，宽约 `784px`，高约 `532px`，支持 `×` / 点击遮罩 / `Esc` 关闭，点击任意题名关闭弹窗并跳转到该题）。
- **弹窗顶栏（最上面一行）**：
  - 左侧：日历图标 + `学习计划` + 紧凑复习间隔标签（如 `间隔 1·2·4·7·15·30 天`）。
  - 右侧：**纯图标按钮组**：参数调节（修改每日新题目标 / 复习上限 / 复习间隔 / 纳入已有通过题目）、导出备份、重置数据、关闭弹窗。
- **单行统计条（1 行紧凑排布，不占多行大卡片）**：
  - `今日新题 X/5 [迷你进度条]` | `今日复习 Y/Z [迷你进度条] [N 逾期]` | `连续打卡 D 天 [已打卡]`，右侧紧凑展示 `本月 M 天 · 已通过 N/100`。
- **主体左右双栏（修正比例，消除右侧留白）**：
  - **左栏（~53%）：VS Code 风格网格月历**（参考 `vscode-extension/src/enhanced/studyCalendar.ts`）
    - 月份切换栏（`‹ 今天 ›`）+ 星期栏（`一~日`）+ 7 列实体细框网格；
    - 单元格近似正方形：左上角日期号，当天右上角标 `今`，下方单行展示 `新X 复Y`（为 0 时弱化）；
    - 低饱和 3 档绿色活跃底纹；选中日期用现有低饱和蓝细内框高亮；未来日期不预排虚假任务；
    - 点击历史日期后，右侧切为 `当日记录`（带 `回到今天` 按钮）。
  - **右栏（~47%）：固定高度内部滚动任务列表（无“查看更多 / 收起”按钮）**
    - 仅 **2 个标签页**：`待复习`（逾期置顶并带 `逾期 X 天` 徽标，左侧圆形复选框支持手动确认复习完成）与 `今日完成`（区分 `新题` / `复习` 小标签，显示时间）；**不加 `今日新题` 标签页**。
    - 内置轻量搜索框 + 紧凑筛选（`全部 / 仅逾期` 或 `全部 / 新题 / 复习`）。
    - 滚动条使用与深/浅主题融合的透明轨道 + 半透明圆角细滑块（`overflow-y: auto`）。

## 三、单题重置与全局重置规格

### 1. 做题页单题重置（方案 A · 无弹窗、无“未通过”残留）
- **位置与触发**：不新增单独按钮。点击现有题目标题行右侧的 **`✓ 已解答`** 绿勾时，**不弹模态弹窗**，而是在 **`✓ 已解答` 正下方就地弹出一个红色小按钮 `重置`**（点击页面其他位置或按 `Esc` 收起）。
- **执行效果**：点击红色 `重置` 后：
  - **`✓ 已解答` 直接消失，不显示“未通过”或任何替代文字**，与从未做过的题目外观完全一致；
  - 移出 `accepted`（总进度减 1），清除 `studyPlan.learned[id]` 复习排期（移出待复习队列，下次通过时重新按**新题**从第 1 天开始复习）；
  - **保留**该题代码草稿、笔记、收藏，以及过往日历打卡记录（不破坏连续打卡天数）；
  - 记录该题 `reset_at` 时间戳，确保多端同步时不会复活。

### 2. 全局重置（通过顶栏 `↺` 或学习计划弹窗右上 `↺` 打开）
- **仅重置学习计划**：清空复习排期与月历计划，保留题库已通过、代码、笔记、收藏与目标设置。
- **重置所有数据（全部清空）**：
  - 清空全部已通过进度（归零）、学习计划与日历打卡、提交记录、收藏、笔记与代码草稿；
  - 防误触：弹窗内置「先导出备份」按钮 + 要求手动输入「重置」二字解锁红色确认按钮；
  - 递增云端 `data_epoch` 并在数据库自动保留一份操作前快照。

## 四、桌面端接入「力扣登录」（对齐 VS Code 插件）

- 复刻 `vscode-extension/src/extension.ts` & `core/browserLogin.ts` 的成熟机制到 Mac / Windows 桌面端（通过顶栏 `👤` 图标打开）：
  1. **浏览器一键登录（推荐）**：启动系统 Chrome / Edge 隔离临时配置窗口打开 `leetcode.cn`（支持力扣 App 扫码），自动读取 `LEETCODE_SESSION` 与 `csrftoken` 后关闭临时配置；
  2. **手动粘贴 Cookie 登录（兜底）**：支持单独粘贴或整段 Cookie 自动拆分；
  3. 登录后支持同步力扣官网 Hot100 通过记录、拉取官网云端提交代码，并在核心代码模式提交至官网。

## 五、腾讯云 Docker + MySQL 数据库与三端同步架构

- **部署目标**：支持 Docker 和 Tailscale 的个人 Linux 服务器；腾讯云只是可选的云服务商之一。
- **基础设施要求（用户指定）**：
  1. 在腾讯云服务器安装 **Docker Engine + Docker CLI + Docker Compose**；
  2. 使用 `docker-compose.yml` 容器化部署 **MySQL 8.0** 数据库容器（挂载宿主机持久化卷 + 定时导出备份）与 **Hot100 同步 API** 容器（HTTPS / 个人同步 Token 鉴权）。
- **MySQL 8.0 核心表设计（6 张表）**：
  1. `sync_meta`：`user_id` (PK), `data_epoch`, `revision`, `plan_settings_json`, `updated_at`
  2. `problem_progress`：`(user_id, problem_id)` (PK), `solved`, `favorite`, `solved_at`, `reset_at`, `updated_at`
  3. `study_plan_learned`：`(user_id, problem_id)` (PK), `first_date`, `last_date`, `stage`, `due_date`, `deleted_at`, `updated_at`
  4. `study_events`：`(user_id, problem_id, event_date)` (PK), `kind` (`new`/`review`), `source` (`test`/`manual`), `created_at`
  5. `code_drafts_notes`：`(user_id, problem_id, lang, mode)` (PK), `code_text`, `note_text`, `content_hash`, `updated_at`, `device_id`
  6. `sync_snapshots`：`snapshot_id` (PK), `user_id`, `reason` (`manual`/`before_reset_all`), `payload_gzip`, `created_at`
- **三端同步机制（Mac 桌面端 + Windows 桌面端 + VS Code 插件）**：
  - 4 步事务推拉：`1. 代际/版本校验 → 2. 拉取增量 → 3. 分域合并（solved_at vs reset_at LWW 墓碑、events 并集、代码冲突保留双副本）→ 4. MySQL 事务落库并 revision+1`。
  - 断网离线优先写本地（`learning.json` / `globalState`），恢复联网自动补传。
