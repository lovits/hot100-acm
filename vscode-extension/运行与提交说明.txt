Hot100 ACM：运行与提交说明

功能
• Hot100 题库：组合筛选、题目搜索、高频排序、标签、企业、提示与题解。
• ACM 模式：编写包含输入、输出和程序入口的完整程序。
• 核心代码模式：按题目模板实现函数或类，插件负责本机测试调用。
• Python、C++、C：支持本机示例测试、自定义测试和全部用例评测。
• 收藏、笔记、刷题进度、月历、间隔复习和学习计划重置。

运行与提交
先点击当前题目的代码文件，再执行命令。
• Hot100 ACM: 本机运行示例 —— 检查题目示例。
• Hot100 ACM: 本机自定义用例 —— 手动填写输入与期望结果。
• Hot100 ACM: 本机评测全部用例 —— 全部通过后更新本地完成记录。
• LeetCode: 提交代码 —— 核心代码提交官网，需要登录；Python/C++/C 的 ACM 文件执行本机全部用例评测。
本机结果见“输出 → Hot100 本机评测”；官网结果见“LeetCode 判题结果”。
本机用例通过与官网判题通过分别记录。

快捷键
打开命令面板：Mac Cmd+Shift+P；Windows/Linux Ctrl+Shift+P。
以下运行、测试、提交、下一题、笔记及收藏快捷键需聚焦题目代码编辑器。

LeetCode: 运行测试
  Mac：Cmd + Option + t    Windows/Linux：Ctrl + Alt + t

LeetCode: 提交代码
  Mac：Cmd + Option + s    Windows/Linux：Ctrl + Alt + s

LeetCode: 下一题
  Mac：Cmd + Option + →    Windows/Linux：Ctrl + Alt + →

LeetCode: 搜索题目（题号/标题/分类）
  Mac：Cmd + Option + f    Windows/Linux：Ctrl + Alt + f

LeetCode: 每日一题
  Mac：Cmd + Option + d    Windows/Linux：Ctrl + Alt + d

LeetCode: 随机抽题
  Mac：Cmd + Option + r    Windows/Linux：Ctrl + Alt + r

LeetCode: 复习错题（到期的优先）
  Mac：Cmd + Option + w    Windows/Linux：Ctrl + Alt + w

LeetCode: 打开题目笔记
  Mac：Cmd + Option + n    Windows/Linux：Ctrl + Alt + n

LeetCode: 收藏/取消收藏题目（本地）
  Mac：Cmd + Option + l    Windows/Linux：Ctrl + Alt + l

测试快捷键：Python/C++/C 执行本机示例测试；其他语言沿用官网测试。
提交快捷键：核心代码提交官网；Python/C++/C 的 ACM 文件执行本机全部用例评测。
“本机自定义用例”和“本机评测全部用例”暂无独立默认快捷键，可从命令面板执行。
