# 运行与提交说明

## 功能

- **题库**：浏览 Hot100，按专题、算法标签、公司、难度、状态组合筛选，支持搜索与高频排序。
- **ACM 模式**：编写包含输入、输出和程序入口的完整程序。
- **核心代码模式**：按模板实现函数或类，插件负责本机测试调用。
- **本机评测**：Python、C++、C 支持示例、自定义用例和全部用例评测。
- **学习记录**：收藏、笔记、进度、月历、间隔复习与计划重置。

## 运行与提交

先聚焦当前题目的代码编辑器，再从命令面板执行：

| 命令 | 功能 |
| --- | --- |
| `Hot100 ACM: 本机运行示例` | 测试题目示例 |
| `Hot100 ACM: 本机自定义用例` | 手动填写输入与期望结果 |
| `Hot100 ACM: 本机评测全部用例` | 全部通过后更新本地完成记录 |
| `LeetCode: 登录` | 登录力扣账号 |
| `LeetCode: 提交代码` | 核心代码提交官网；Python/C++/C 的 ACM 文件执行本机全部用例评测 |

本机结果在 **输出 → Hot100 本机评测** 查看；官网结果在 **LeetCode 判题结果** 查看。
本机用例通过与官网判题通过分别记录。

## 快捷键

打开命令面板：**Mac `Cmd + Shift + P`**；**Windows/Linux `Ctrl + Shift + P`**。

| 功能 | Mac | Windows/Linux |
| --- | --- | --- |
| 运行测试 | `Cmd + Option + t` | `Ctrl + Alt + t` |
| 提交代码 | `Cmd + Option + s` | `Ctrl + Alt + s` |
| 下一题 | `Cmd + Option + →` | `Ctrl + Alt + →` |
| 搜索题目（题号/标题/分类） | `Cmd + Option + f` | `Ctrl + Alt + f` |
| 每日一题 | `Cmd + Option + d` | `Ctrl + Alt + d` |
| 随机抽题 | `Cmd + Option + r` | `Ctrl + Alt + r` |
| 复习错题（到期的优先） | `Cmd + Option + w` | `Ctrl + Alt + w` |
| 打开题目笔记 | `Cmd + Option + n` | `Ctrl + Alt + n` |
| 收藏/取消收藏题目（本地） | `Cmd + Option + l` | `Ctrl + Alt + l` |

运行、测试、提交、下一题、笔记和收藏快捷键需聚焦题目代码编辑器。

- **测试快捷键**：Python/C++/C 执行本机示例测试；其他语言沿用官网测试。
- **提交快捷键**：核心代码提交官网；Python/C++/C 的 ACM 文件执行本机全部用例评测。
- **自定义用例、全部用例评测**：通过命令面板执行，暂无独立默认快捷键。
