# Hot100 ACM

在 VS Code 中浏览、编写和测试 Hot100 算法题，安排每日练习与间隔复习。

## 功能

- 支持 ACM 与核心代码模式，分别保存代码草稿。
- 每次打开题目选择语言，使用原生编辑器编写代码。
- 支持 Python、C++、C 的本机示例测试、完整用例评测和自定义测试；其他语言保留对应的既有功能。
- 按专题、算法标签、公司、难度、状态组合筛选，支持搜索与高频排序。
- 查看题面、题解、标签、提示、相关企业及考察次数，点击题名打开力扣原题。
- 收藏题目、记录笔记、查看进度和连续打卡。
- 使用月历查看学习记录，设置每日新题目标和复习间隔，管理待复习与已完成题目。

## 使用

从 [GitHub Release](https://github.com/lovits/hot100-acm/releases/tag/vscode-v0.2.3) 下载 VSIX，在 VS Code 中选择“从 VSIX 安装”，打开工作区后进入插件侧栏。
本机测试使用已安装的 Python 解释器或 C/C++ 编译器；学习记录保存在扩展存储，代码草稿保存在工作区。
