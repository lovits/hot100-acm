# 更新记录

## 0.1.0 — 2026-11-17

- 新增 VS Code 原生编辑器刷题界面与 100 题列表。
- 支持 Python/C++/C，ACM/核心代码模式、示例运行、全用例提交、自定义用例。
- 使用官网完整题面及三语言函数签名，显示分类、难度、公司频次。
- 按题号、语言、模式保存独立代码草稿；记录通过状态。
- 使用 VS Code 主题色，支持键盘选题和窄窗排版。

## 0.2.0 — 2026-11-17

- 基于 LeetCode Hot100 Pro v0.1.17 的源码增强，保留原有题面、题解、登录、笔记和官网流程。
- 增加默认 ACM 与核心模式切换标签，使用 VS Code 本机工具链评测三种语言。
- 增加组合筛选、公司频次、高频排序。
- 增加可修改目标、复习间隔与每日上限的两周计划表，保留逾期任务及历史记录。
- 隔离增强版命令、配置与侧栏标识。
